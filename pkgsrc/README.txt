The game's own Lua code is unmodified; the port adds a software renderer and
handheld controls/options around it (see the GitHub page for details).

Install: copy the Roms folder to the root of the SD card (or install it with
Mixtape). Launch "Mr. Rescue" from Games > Ports (OnionOS needs the "Ports"
system, from Package Manager > Verified, to show the Ports list).

Controls
  D-pad          move / climb ladders / menus
  B              jump            (menus: back)
  A              grab / throw    (menus: OK)
  Y, X, L1, R1   shoot water (hold Up or Down to aim)
  Start          pause
  Select         back
  Select+Start   quit

Options > Screen: SHARP (crisp 2x pixels with a border), FIT (fills the
height, keeps proportions) or STRETCH (fills the whole screen).

Saves and settings live in Roms/PORTS/Games/MrRescue/data. The log of the
last run is Roms/PORTS/Games/MrRescue/log.txt; please attach it to reports.
